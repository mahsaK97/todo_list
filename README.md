# To-Do List

A simple and responsive To-Do List application built with Vanilla JavaScript.

## Features

* Add new tasks
* Edit tasks
* Delete tasks
* Assign categories to tasks (Personal, Study, Work)
* Add deadlines to tasks
* Mark tasks as completed
* Save tasks using Local Storage
* Restore tasks after refreshing the page
* Responsive design for different screen sizes
  
## Technologies

* HTML5
* CSS3
* JavaScript (Vanilla)
* Local Storage

## Categories

Each task can be assigned to one of the following categories:

* Personal
* Study
* Work
